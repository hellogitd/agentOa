# 模块 8：报表与工作台开发计划

## 目标与边界

基于已验收业务表提供只读指标和工作台。P0 包括员工/组织概览、考勤月报、费用统计、流程效率四类看板、权限过滤和人工导出；实时数仓、拖拽自定义报表、定时邮件和 BI 外部连接列为 P1/P2。

## 开发顺序

1. V11 迁移指标字典、报表口径版本和导出任务记录，不复制事实表。
2. 为每项指标写 SQL/服务口径：时间范围、时区、状态、去重、组织过滤、数据更新时间；口径变更升版本。
3. 实现只读查询服务，所有查询先应用对象权限和部门范围；大导出使用异步任务和私有文件。
4. 实现工作台卡片、趋势、异常列表、钻取详情和 CSV/XLSX 导出；导出记录操作者、过滤条件和版本。
5. 接入 M4 H5：审批待办、今日打卡、公告和关键余额只调用已验证 API。

API：`GET /api/v1/reports/overview`、`/attendance`、`/finance`、`/workflow`、`/exports/{id}`；导出接口必须有分页、上限和幂等键。

## 测试与退出条件

测试同一口径下列表与报表对账、部门权限、时间边界、撤销/拒绝状态过滤、导出大数据量、敏感字段脱敏和报表版本兼容。退出条件是业务负责人签字确认四类口径，且报表不修改业务事实。

## 实施记录（2026-10-04，P0 开发完成，待验收签字）

P0 已交付，接口以 [05](05-api-spec.md) 第 10 节（10.1 实现口径补充）为准，与本文档草案的差异如下：

- 路径/权限对齐 05：`GET /api/v1/report/dashboard/workbench`（工作台：待办、我发起的、今日日程、公告、考勤状态、关键余额、快捷入口与管理视角卡片）、`GET /api/v1/report/hr|attendance|finance|flow/statistics`（四类看板）、`GET /api/v1/report/export/{type}`（同步导出）、`GET /api/v1/report/metrics`（指标字典与口径版本）、`GET /api/v1/report/details/{type}`（钻取明细）、`POST/GET /api/v1/report/exports` 与 `GET /api/v1/report/exports/{id}`（导出任务记录）。本文档草案的 `/api/v1/reports/overview|attendance|finance|workflow|exports/{id}` 不再使用。权限串 `rp:report:list`（看板/指标/明细）、`rp:report:export`（同步导出与导出任务），工作台与本人导出记录仅需登录；数据范围为超管或 `hr`/`finance`/`director` 角色看全量、其余角色本部门，导出与列表同一权限与筛选口径。
- V11 迁移：`oa_report_metric`（指标字典）、`oa_report_metric_version`（口径版本，口径变更即升版本）、`oa_report_export`（导出任务记录：操作者、过滤条件、格式、行数、口径版本快照、私有文件 ID、幂等键）；`rp_metric_category`/`rp_report_type`/`rp_export_format`/`rp_export_status` 字典、`rp:*` 菜单（2700–2711）与角色授权（HR/部门经理/财务/总监看板与导出，普通员工与出纳仅工作台自助）。不复制事实表，报表只读。
- 指标口径：18 项指标（人事 5、考勤 4、财务 4、流程 5）在迁移中登记口径定义 JSON（时间范围、时区、状态过滤、去重键、组织过滤、数据更新时间），服务端按 [02](02-requirements.md) 13.4 执行：区间为自然日闭区间（内部左闭右开）、出勤率=实际出勤分钟/（计划−已批准请假）分母为零返回空、请假分钟按 480 分钟/天折算、申请/批准/实付分列不混计、平均处理时长仅计已通过实例且拒绝/撤销/终止单列、超时为在途实例发起后超 24 小时。费用类型分布沿用模块 4 报表口径（`status IN (3,5,6)` + 发生日期区间），待办/已办口径与流程待办列表一致（Flowable 运行时任务办理人或候选人）。
- 导出：同步导出（`GET /export/{type}`，CSV/XLSX，上限 10000 行）与异步导出任务（`POST /exports`，必须携带 `Idempotency-Key`，同键同请求重放首次结果、同键异请求 409，上限 50000 行）共用同一 SQL 口径与数据范围；异步任务由调度器轮询领取（状态条件更新防重复执行），文件写入私有 S3 与 `sys_file`，下载走 `/api/v1/files/{fileId}/download` 属主校验；每次导出都记录操作者、过滤条件与口径版本快照，超限返回 `RP_EXPORT_LIMIT`，明细分页接口支持分段取数。敏感字段（手机号/身份证/邮箱）在报表明细与导出中一律脱敏。
- 前端 `views/report/{hr,attendance,finance,flow,exports}` + `views/report/components`（指标卡、图表、口径表）+ `api/report`；工作台首页（`views/index.vue`）改造为 docs/02 9.2 布局（我的待办、我发起的、今日日程、公告、快捷入口、考勤状态、关键余额、管理视角），保留站内消息、我的文件与基础服务验证入口；四类看板提供指标卡、趋势/分布图表（ECharts）、异常列表、钻取明细分页与导出，导出记录页支持任务创建、状态、过滤条件、口径版本与文件下载。
- 对前置模块无登记变更；工作台数据按已验证接口同一口径只读聚合，未新增通知或流程能力。
